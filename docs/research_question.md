# Research question

Does a fault-triggering test satisfy the historical mutant–real-fault coupling criterion more often than a comparable ordinary non-triggering test?

The core construct is discriminant validity of mutant–real-fault coupling.

The primary estimand is excess coupling: trigger-test coupling rate minus matched non-trigger coupling rate, on the same kill matrices, with coverage gain as the primary matching variable.

See the parent scientific contract for the frozen identity. This artifact repository does not redefine that object.
