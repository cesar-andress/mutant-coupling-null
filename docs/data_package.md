# Canonical data package (v1.0.0)

## Contents

481 canonical Major 3.0.1 kill maps (plus `trigger_tests.txt`) for matrix-available
Defects4J 3.0.1 bugs. Parser-excluded maps (10 duplicate test-identifier cases)
are **not** included.

Archive: `mutant-coupling-null-canonical-data-v1.0.0.tar.gz` (GitHub Release asset).
Manifest: `docs/release/CANONICAL_MAP_MANIFEST.csv`.

## What is not included

- Defects4J source trees
- Major binaries
- project checkouts
- the 10 parser-excluded maps
- mutation-failure / timeout / build-failure directories

## Provenance

Generated by the pinned Defects4J 3.0.1 (`6d54320e0db5a357f9ab38a8e4d2e5aead7e1c09`)
/ Major 3.0.1 / OpenJDK 11 mutation workflow on **fixed** revisions, using the
kill-map export patch in `acquire/patches/`.
